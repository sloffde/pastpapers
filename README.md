# SLOFFDE 历年题站（pastpapers）

Ginkgo 构建的本科医学历年题交互站点，属 SLOFFDE 项目。

- 线上：<https://sloffde.github.io/pastpapers/>
- 构建工具：[Ginkgo](https://github.com/YangShu233-Snow/Ginkgo)（MIT）
- 结构：`docs/<年级>/<科目>/<学年>-<学期>-<类型>.md`

## 本地预览

```bash
pip install ginkgo-flashcards
ginkgo serve          # http://127.0.0.1:7777，监听 docs/ 变化
```

## 贡献

见 [CONTRIBUTING.md](./CONTRIBUTING.md)。格式样例：`docs/大一/系统解剖学/2023-2024-期末.md`。
